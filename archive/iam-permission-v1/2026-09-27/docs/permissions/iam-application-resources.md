# IAM 应用与权限资源权限约束

> 来源：`docs/prd/iam/application-permission-resources.md` 与 `docs/api/iam-application-resources-api.md`。

- 页面、完整目录和全部维护入口仅向集团超级管理员（SA）开放。
- 导航入口由服务端菜单结果决定；前端不发明新的权限编码，也不以是否显示按钮作为安全边界。
- 每个 App、资源的写入口同时受响应字段 `can_maintain` 约束，服务端仍需对每次请求重新鉴权。
- 非 SA 直接访问时进入 Unauthorized 状态，不加载或展示目录、接口路径、权限编码等管理数据。
- 401 进入统一重新认证；403 清空当前管理数据并离开页面；版本冲突保留用户输入但不得覆盖服务端结果。
- App 或资源变更成功后必须刷新完整目录和当前用户权限结果，避免继续使用失效的入口、路由或功能权限。
