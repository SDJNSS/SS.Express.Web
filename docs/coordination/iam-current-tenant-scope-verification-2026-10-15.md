# IAM 当前租户范围前端检查结果

日期：2026-10-15。依据 `docs/coordination/iam-current-tenant-scope.md`；本文件仅记录已验证的前端事实，不代表后端数据隔离验收完成。

历史记录说明（2026-10-16）：下文“SA 平台全局入口”仅描述当时的决定，已被最新同步规则取代。当前集团与 Tenant 目录使用当前 Tenant 授权；Tenant/Query 的目录范围与 SA 写操作限制按更新后的 `iam-current-tenant-scope.md` 执行。

## 已符合及已改造

- 员工、组织、岗位、角色、角色成员、权限方案和培训业务请求按当前租户传参；员工列表无租户多选，组织/岗位/角色候选也限当前租户。
- 框架切换候选仅来自登录会话可进入租户。成功切换才更新会话并返回欢迎页；失败保留原上下文。无租户时阻止业务查询，跨租户直链在业务请求前拦截，旧响应不能落入新租户。
- 员工详情只显示当前租户成员关系；旧跨租户归属编辑和全量替换接口已从该页停用。共享用户身份编辑保留独立权限及影响提示。
- 集团信息、租户管理保留 SA 平台全局入口；系统资源目录保持已有平台权限范围。
- 对应 Page Contract 与员工查询契约已更新为当前租户规则；未自行批准新的视觉结果。

## 验证结果

- `pnpm page-contract:check`、`pnpm standards:check`、`pnpm prototype:legacy-check`、`pnpm lint:code`、`pnpm typecheck`、`pnpm test:typecheck`、`pnpm ui:typecheck`、`pnpm build`、`pnpm ui:build` 通过。
- 员工、IAM 基础、角色及 HTTP 隔离定向浏览器测试：1366×768、1440×900、1920×1080 合计 75 项通过。培训相关定向浏览器测试在 1440×900 的 13 项通过；员工旧流程回归 2 项、基础 Preview 交互 4 项、DMS 切换后旧上传响应 1 项通过。
- `pnpm test:governance` 89/91：两项独立通信证据复核阻断，分别是占位页来源证据变化和 `auth.login` 通信链依赖变化。`pnpm quality` 因相同通信链关口未全绿；不能只刷新摘要绕过复核。
- 三个改动页的 `page-contract:production` 被旧 Approval 的规格版本及三视口基线摘要阻断；全量视觉运行发现多张既有 approved 图与当前渲染不同。未重录截图或修改 Approval，需 UIDesign 人工复审。

## 待联调与责任

1. 后端：核对当前 Token 租户对所有租户业务接口的强制隔离，包括嵌套成员、筛选候选、导出；集团信息与租户管理保持 SA 限制。前端限制不能替代后端鉴权。
2. 前后端联调：用同时属于 A/B 的用户及 SA，在真实服务上验证切换、直链、旧请求、无权限和刷新恢复。现有浏览器测试使用模拟响应，不得视为真实 A/B 联调通过。
3. UIDesign 审核人：复审员工、角色管理、角色成员的当前版视觉和 Page Contract，再由正式流程更新 Approval 与三视口基线；不能自动沿用旧批准。
4. 系统资源维护会话：独立复核占位页与 `auth.login` 通信链证据，解除治理关口后再跑全量质量链；本次不执行资源同步或授权写入。
