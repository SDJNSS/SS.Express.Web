# 字典正式页：原SA身份字段建议已撤回

2026-10-29，用户已明确决定：“不必使用is_sa方案。我们控制写按钮仅分配给SA即可。”本文替代此前同路径的字段补充建议，避免后端继续按旧要求开发。

正式路由：`/iam/dictionaries`。前端按CurrentPageResources返回的页面与按钮资源判权，查询权限和八个写按钮权限独立；不推断SA身份，不依赖CurrentProfile.is_sa，不为字典页额外调用CurrentProfile。

后端无需为此页面补充SA身份字段或新增身份查询端点，现有接口契约可继续使用。

- 后端写接口继续独立执行SA及精确Function校验，前端隐藏按钮不替代服务端安全边界。
- Query、QueryItems保留已授权普通用户读取能力，供本页只读及其他业务选项使用。
- 资源维护方登记页面及按钮后，仅为SA角色分配写按钮对应Permission；未获得按钮资源时，前端不展示相应写操作。
- 前端仅维护代码、资源声明及离线产物，不写数据库或自动分配权限。
