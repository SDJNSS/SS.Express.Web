# 在线培训考试：培训资源与考试规则

> 来源：用户提供的《在线培训考试模块-第一组-培训资源与考试规则-前端PRD》。本文件作为前端 Page Contract 的仓库内受控依据，不替代原始 PRD。

## 范围

本组覆盖 PC Web 管理端的四个菜单：课程管理、题库管理、试卷管理、考试配置管理。页面面向具备相应权限的安全培训管理员；普通员工不进入这些管理页面。本组不包含学员端、培训计划与任务、实际答题、删除、批量导入和批量状态操作。

## 通用规则

- 数据限定在当前 Tenant，页面不得采集 Tenant、App 或操作人等上下文字段。
- 状态为 `DRAFT`、`ACTIVE`、`DISABLED`；允许草稿启用、启用停用、停用重新启用，不允许返回草稿。
- 创建记录默认进入草稿，不提供创建时直接启用。
- 列表查询使用服务端分页；改变筛选条件后回到第一页。
- 状态操作必须展示对象、影响和确认动作，等待服务端确认后再刷新状态；冲突时保留上下文并刷新权威数据。
- 页面访问权限与功能权限分离；前端只负责可发现性和交互，服务端仍是授权来源。
- 创建、编辑成功后默认进入详情；状态操作留在当前上下文。
- 不做前端名称唯一性判断；字段级与业务级错误由正式接口接入时映射。

## M02 课程管理

- 筛选：课程名称、培训类型、状态、锁定状态。
- 列表：课程名称、培训类型、视频时长、计划学习时长、状态、锁定状态、更新时间与操作。
- 详情：基础信息、视频资源摘要、两类时长、状态与锁定信息、审计信息。
- 创建/编辑：课程名称 1–200 字符；培训类型必填且最多 50 字符；课程说明；单个视频；视频时长与计划学习时长必须相同且大于 0。
- 上传区展示文件选择、校验、进度、成功、失败与重试，不暴露对象存储、签名或鉴权细节。
- 已锁定课程的核心内容只读，但允许复制和状态操作。
- 复制生成新的草稿、未锁定课程，复用视频引用，不复制上传过程和历史关联。

## M03 题库管理

- 筛选：题干关键词、题型、状态。
- 列表：题目 ID（只读）、题干摘要、题型、状态、更新时间与操作。
- 题型：单选题、多选题、判断题。
- 选项标签必填、唯一、1–10 字符；页面顺序连续。
- 单选题至少 2 个选项且恰好 1 个正确；多选题至少 3 个选项且一个或多个正确；判断题固定 2 个选项且恰好 1 个正确。2026-10-24已核对本地后端同步放宽，真实环境部署及联调另行确认。
- 切换不兼容题型前必须确认清空原选项，不得静默丢失。
- 详情展示完整题干、有序选项、正确答案、解析与审计信息；答案和解析属于管理端敏感内容。
- 编辑任何状态的题目不改变其状态，并提示历史考试使用快照、不受本次修改影响。

## M04 试卷管理

- 筛选：试卷名称、组卷模式、状态。
- 列表：试卷名称、组卷模式、总分、状态、更新时间与操作。
- 固定组卷：选择启用题目、题目唯一、分值大于 0 且最多两位小数、支持排序。
- 随机组卷：按单选、多选、判断分别配置题量和题型总分，精确均分得每题分值；题量为非负整数，全卷1–1000题，题量不得超过可用题数；题量为0时分值清空并禁用。显式预览后维护具体题集。
- 目标总分大于 0 且最多两位小数；实时计算总分必须与目标总分一致才能保存。
- 切换组卷模式前确认，并清空另一模式的专属配置。
- 固定组卷与随机组卷分别提供“题目顺序随机”和“选项顺序随机”独立开关。
- 编辑时已停用的原题可保留但不可重新选择；详情和编辑均提示历史考试快照规则。

### 2026-10-23 选题与最终题集（用户确认）

- 本轮改造属于试卷管理；考试配置继续选择试卷，不重复建设组卷功能。
- 固定组卷使用“选择题目”抽屉，按题型分 Tab；各 Tab 独立题干关键词、每页20条服务端分页。勾选跨页、跨 Tab 和重新打开保留；取消不改变试卷，确认后应用。临时选题状态不写 URL，归属尚未提交的表单。
- 已选题按题型分组，完整显示题干及 ID；支持移除、替换与组内上移/下移。替换可跨题型，每次替换一题，其他已选题保持勾选且不可重复选择，原题仅在确认替换时移除。
- 新试卷按题型设置总分，均分至两位小数必须精确，不要求整数分、不四舍五入。例如1/4=0.25、9.99/3=3.33有效，10/3无效。计算使用整数百分单位。题数变动清空对应题型总分；跨型替换清空来源与目标分组，同型同题数替换保留分值，其他分组和目标总分不变。空分组不保存分值。
- 2026-10-24用户明确不再兼容旧数据，由用户/后端全部清除；前端不清理数据库、不自动平均旧分值、不自动迁移旧规则卷。新的固定/随机卷均只保存具体最终题集。
- 随机组卷先按题型规则生成预览，再对这份题集移除/跨型替换并同步实际题数，分组计分规则同上。预览确认后的具体题集是正式考试最终题集，保存/回读/考试不再重抽；题目顺序、选项顺序随机独立保留。重新设置规则必须确认清空人工调整，且再次显式预览才抽题。
- 已按本地后端最终契约接入正式 GeneratePreview、Create/Update/Detail；每题提交实际题型和原始更新时间。保存/回读不重新抽取；版本冲突保留输入，不自动换题或刷新版本。隔离 Preview 仍仅使用确定性样例，生产不使用 Mock 回退。真实环境联调不等同受控接口测试。
- 后端协作见 `docs/coordination/training-paper-selection-backend-requirements-2026-10-23.md`；前端不修改数据库或维护在线资源。

## M05 考试配置管理

- 筛选：配置名称、状态。
- 列表：配置名称、试卷、考试时长、及格分、最大考试次数、状态与操作。
- 创建/编辑：配置名称 1–200 字符；新选择的试卷必须启用；考试时长为正整数秒；及格分在 0 与试卷总分之间且最多两位小数；最大考试次数为大于等于 1 的整数并包含首次考试。
- “考后展示正确答案”和“考后展示答案解析”为两个独立开关，默认关闭。
- 编辑时原先关联但已停用的试卷可保留，不可重新选择其他停用试卷。
- 详情展示试卷摘要、组卷模式、总分、时长、及格分、次数、考后展示策略与审计信息。
- 页面明确说明配置更新只影响后续创建的考试实例，历史实例按快照执行。

## 2026-10-22 课程详情视频预览

- 复用课程详情抽屉，打开详情后自动申请临时地址并预加载首帧；不自动播放、不自动出声，不在列表批量取链。保留“重新加载视频”恢复入口。
- 原生播放器提供暂停/播放、拖动、音量及全屏。显示真实文件名、大小；不把文件 ID 冒充名称。
- 根据 expires_at 续签并保留进度、音量、倍速及播放/暂停意图；失败停播并显示可重试错误，不无限重试。
- 关闭详情、切换课程、当前租户或会话变化后停止媒体、取消请求及定时续签；旧结果不得覆盖新上下文。
- 缺少附件、服务不可用、无权限、网络失败及不兼容格式/编码均有明确提示；MOV/AVI 兼容与真实存储播放由后端协同，不伪造转码能力。
- 只读管理员预览不写员工学习开始、心跳、完成或考试数据。Preview 不注入真实传输、不请求 DMS/OSS。
- 等待 loadeddata 并确认非零视频尺寸后才认定画面可用，缺少画面时停止媒体并显示原因提示，不能只凭 metadata/duration 认定正常播放。使用 Element Plus 风格中央播放按钮和既有原生媒体控件。
- 2026-10-23 后端新增同步标准化和持久缩略图，按下述增量接入；缩略图缺失时仍使用真实解码首帧降级，不冒充已生成封面。

## 2026-10-23 同步视频标准化与缩略图

- 新上传 MP4/MOV/AVI 由 DMS 在单次请求内生成标准化播放文件和缩略图；不增加异步任务或轮询。上传字节 100% 后继续等待转换及保存，不提前宣告成功。
- 上传最终响应及 ValidateVideo 均成功后才启用业务保存；课程仍仅提交稳定 video_file_id，时长使用服务端最终 media_duration_ms 向上取整。只有 ready 响应才显示已转换，缩略图 failed 不阻断视频引用。
- 详情继续自动取链、不自动播放；使用 GetAccessUrl 的临时 thumbnail_url 作为 poster，视频与缩略图中较早的有效租约到期前统一续签并保留进度。缩略图缺失、失效或加载失败不得阻断视频，不为封面增加 Function、API 或后台 Token。
- URL 只存在打开详情的内存状态，关闭移除视频及 poster。历史 unprocessed 视频明确提示尚未标准化，不能宣称此次前端改造已转码旧文件。
- 完整接口及部署边界见 `docs/api/dms-files.md` 的同步视频标准化章节；不更新数据库、历史文件或人工批准基线。

## 2026-10-23 课程新建编辑的视频核对与限制

- 用户确认统一采用上传后预览，不新增上传前本地播放器或手动开始上传步骤。编辑已有课程时直接预览当前附件；更换文件后停止旧视频，等待 Upload 和 ValidateVideo 完成，再自动加载新视频与缩略图供保存前核对。不自动播放。
- 预览复用课程详情播放器及 GetAccessUrl，关闭编辑、移除文件、切换会话/Tenant/App 时释放媒体和请求。预览失败可独立重试，不重复上传，也不把已成功上传的视频改为失效；业务保存仍等待上传/校验成功。
- 新选择的视频单个上限为 200MB（200×1024×1024字节），时长不超过600秒。选择时先检查大小，再尽力读取浏览器原片元数据；明确超过600秒时不上传。无法识别或预检超时保留说明，允许后端转码，不以不兼容误判超长。
- 无论本地能否识别，转换后以服务端返回时长再校验，超过600秒不产生可用文件事件、不保存课程。浏览器预检不能保证未识别超长原片不进入存储，后端需对 Upload/ValidateVideo/课程写入做权威校验，详见本轮协调说明。旧课程不因此次新增上传限制自动失效。
