# IAM 登录页需求

## 需求来源

- 当前用户要求：根据所附效果图设计物流平台登录页。
- 视觉参考：`docs/design/references/iam-login.png`。
- 参考图只用于“左侧品牌与登录表单、右侧物流主题视觉、深色桌面画面”的构图证据，不继承图中的 TMS 品牌、账号数据、版权信息或后端行为。

## 页面目标

为 IAM、TMS、VMS 等子系统提供统一的未认证入口。页面视觉沿用已批准 Candidate，生产页面接入 IAM Login 接口，并保持 Preview 使用静态 Fixture。

## 候选范围

- 使用简体中文和项目现有 Design Token、Element Plus 与 Iconify。
- 页面为独立认证页面，不显示登录后的 `AppShell`。
- 展示陆链控制台品牌、账号、密码、记住我、忘记密码和登录动作。
- 密码默认遮罩，提供键盘可操作的显示/隐藏按钮。
- 空提交时展示字段错误并聚焦首个错误字段。
- 提供提交中、通用认证失败和候选交互反馈状态。
- 右侧视觉表达“统一身份通行轨迹”，关联 IAM、TMS、VMS，不复制参考图中的品牌和插画。
- 在 `1366×768`、`1440×900`、`1920×1080` 三个桌面视口验证。
- 生产登录调用 `POST /iam-admin/Auth/Login`；完整契约见 `docs/api/iam-auth.md`。
- `AUTHENTICATED` 登录状态进入安全站内回跳地址或平台工作台。
- `INITIAL_PASSWORD_CHANGE_REQUIRED` 暂按受限欢迎会话处理：进入框架欢迎页，但不加载模块、菜单、用户资料或 Dashboard 数据，也不能进入其他业务路由。
- 认证失败保留账号、清空密码，并统一显示不暴露账号状态的错误文案。

## 非目标与后续范围

- 租户选择、初始密码修改、验证码、MFA、OAuth 与完整会话的前端权限目录加载是独立流程，本次不推断其页面或接口。
- “忘记密码”的页面已单独批准，但真实找回接口尚未提供；登录页当前给出明确提示。
- 生产接入不得修改已批准页面构图、Design Token 或三视口基线。

## 验收

1. 页面保持参考图的左右分区关系，同时呈现陆链平台自己的视觉身份。
2. 账号、密码、记住我、忘记密码、密码显示/隐藏和登录动作均有明确交互反馈。
3. 表单错误使用文本呈现，密码不会写入 URL、日志、通知或持久存储。
4. Preview 不产生业务网络请求；Production 只通过统一 HTTP Client 调用 IAM 服务。
5. 三个标准视口无页面级横向溢出或关键内容裁切，生产页与批准基线一致。
6. 初始密码受限会话登录后进入 `AppShell` 欢迎页，不请求受后端限制的框架上下文接口，并将其他业务路由收敛到欢迎页。
