# 字典管理

2026-10-29。来源：用户需求及后端 `iam-dictionary-api-contract-2026-10-29.md`。用户已明确审核通过并授权正式开发；同一canonical现由隔离Preview和正式binding复用。

## 目标与边界

按当前页面及按钮资源权限维护平台公共字典和字典值。用户最新决定：“不必使用is_sa方案。我们控制写按钮仅分配给SA即可。”有页面查询权限的用户可读，八个写按钮各自精确判权并仅分配给SA；前端不增加SA身份前置条件，后端写接口继续强制SA及对应Function校验。平台共享，不出现Tenant筛选或提交tenant_id。字典不是租户业务流水，其编码是稳定业务键：创建填写，编辑只读，删除后不重用。

## 列表与抽屉

- 列表：字典编码、名称、状态、描述、更新时间；编辑、启用或停用操作紧凑显示，无删除入口。点击编码或名称打开右侧字典值抽屉，不通过整行点击打开。
- 筛选：完整字典编码精确查询、名称等关键词模糊查询及状态，条件取交集。默认状态全部，含停用记录；显式查询/重置，刷新保留已提交筛选。默认每页20条。
- 抽屉：字典名称、编码、描述，字典值关键词、状态筛选和独立分页；状态默认全部，包含停用和既有未设置状态。
- 字典值列：编码、名称、自身状态、业务可用性（is_available）、排序、颜色或标签、描述、JSON扩展数据、紧凑编辑和启停按钮。长JSON显示文本摘要，完整值在编辑表单查看，不执行HTML或CSS。
- 新建字典可选填最多 200 个初始值，原子提交；可不填初始值。新建表单均为空，不将 Fixture 写入表单默认值。
- 新建/编辑字典值包括名称、描述、排序、颜色/标签、状态、JSON。编辑不改编码或所属字典；既有 null 状态显示未设置，保存前需显式选择合法状态。

## 保存、版本和启停

- 版本是原始 Int64 字符串，字典和值独立；空更新时间对应真实版本字符串 `"0"`。不在浏览器计算版本，不把一个版本覆盖到另一对象。
- 完整字段回传，保留 false、0、空 JSON 字符串和 null。UTF-8 JSON 最大 16 KiB。
- 错误保留输入；版本冲突要求用户刷新核对，不自动覆盖。提交结果未知禁止自动重放，创建可按编码查询核对，不把超时视为保存失败后可直接重复提交。
- 用独立Enable/Disable、EnableItem/DisableItem替换原删除入口，确认后提交当前字符串版本，八个写按钮各自精确判权。active显示停用按钮；disabled或既有未设置状态显示启用按钮。
- 停用字典不删数据、不改子值自身状态/版本，但全部值不可用于新业务；启用字典只恢复自身active子值的可用性，单独disabled的值仍停用。启用单个值不启用父字典，父字典停用时该值仍不可用。历史业务记录不改写。
- 默认Query/QueryItems读取全部未删除记录供管理；QueryItems(status=active)仅展示父字典和值均active的可用选项。资料编辑保留既有值status字段能力，列表启停必须调用独立接口。
- 草稿关闭需确认，继续编辑保留表单；提交中禁止重复提交/关闭。查询失败不冒充空数据，允许显式重试。

## 当前交付边界

后端契约记录12个接口已实现部署。正式路由`/iam/dictionaries`接入10个实际使用端点，后台Delete/DeleteItem不暴露。页面已批准，固化本页三视口基线，使用正式iam-resource.registry.ts；Preview仍只用Fixture，正式环境无Mock回退。资源入库、角色授权与真实用户环境验收独立，不在前端开发中自动写数据库或补授SA权限。

正式binding仅校验当前页精确资源及对应按钮资源，不为字典页额外调用CurrentProfile，不要求is_sa字段。统一HTTP处理envelope、reason_code与原始版本；URL保存dictTypeCode/keyword/status/pageIndex/pageSize并支持回退恢复，单次操作不重复查询。真实运行仍须维护方入库授权就绪；写按钮误授普通用户时，后端SA拒绝必须正常展示，不得冒充提交成功。
